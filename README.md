# The Mushroom Rush 🍄

**Experience Latvia's Autumn Obsession**

An immersive interactive experience that teaches you about Latvia's beloved mushroom foraging tradition through storytelling, education, and an engaging AI-powered game.

## Features

- 📖 **Immersive Storytelling**: Learn about Latvian autumn culture through grandmother's wisdom
- 🎓 **Educational Content**: Identify edible and poisonous mushrooms safely
- 🧠 **AI-Powered Quiz**: Test your knowledge with an interactive test
- 🎮 **Hand-Tracking Game**: Use your hands and camera to simulate real mushroom foraging with gesture recognition
- ✨ **Beautiful Animations**: Smooth transitions and interactive elements powered by GSAP

## How It Works

1. **Welcome**: Meet your grandmother and learn about the tradition
2. **Learn**: Study the characteristics of safe and dangerous mushrooms
3. **Test**: Take an interactive quiz to prove your knowledge
4. **Hunt**: Use your webcam and hand gestures to forage virtual mushrooms

## Technology

- HTML5, CSS3, JavaScript
- [TensorFlow.js](https://www.tensorflow.org/js) & [Teachable Machine](https://teachablemachine.withgoogle.com/) for AI model
- [ml5.js](https://learn.ml5js.org/) for hand pose detection
- [GSAP](https://greensock.com/gsap/) for animations

## Getting Started

Simply open `index.html` in your web browser. For the full experience, allow camera access when prompted.
